PWA 可安装iOS · 安卓 · 平板扫码即用

📲 安装到手机 / 平板

  1. 用 iPhone/iPad 的 Safari，或安卓的 Chrome 扫描二维码，打开本页。
  2. 点击下方卡片进入「学习器」「测试器」「快速播放器」「闪记」「复习」或「错题专练」。
  3. 添加到主屏幕：iOS 点底部分享按钮 →「添加到主屏幕」；安卓 Chrome 点菜单 →「安装应用」。
  4. 之后主屏幕就会出现 App 图标，点开即全屏使用，就像原生 App 一样。
提示：看板数据全部来自本机 localStorage，无网络上传。换设备不会自动同步；如需迁移可在每个 app 内用 ⤴ / ⤵ 按钮导出/导入 JSON。
提示：若点击「播放解说 / 测试」听不到声音，请用 Safari 或 Chrome 打开本页面。
