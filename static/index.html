PWA 可安装iOS · 安卓 · 平板扫码即用

📲 安装到手机 / 平板

  1. 用 iPhone/iPad 的 Safari，或安卓的 Chrome 扫描二维码，打开本页。
  2. 点击下方卡片进入「学习器」「测试器」或「快速播放器」即可使用。
  3. 添加到主屏幕：iOS 点底部分享按钮 →「添加到主屏幕」；安卓 Chrome 点菜单 →「安装应用」。
  4. 之后主屏幕就会出现 App 图标，点开即全屏使用，就像原生 App 一样。
提示：安装后会自动缓存应用文件，首次加载后无网络也能继续使用。若存储空间不足导致缓存失败，仍可联网使用。
