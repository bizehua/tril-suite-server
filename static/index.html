📲 安装到手机 / 平板📲 Pasang ke Telefon / Tablet

  1. 用 iPhone/iPad 的 Safari，或安卓的 Chrome 扫描二维码，打开本页。Guna Safari (iPhone/iPad) atau Chrome (Android) imbas kod QR untuk buka halaman ini.
  2. 点击下方卡片进入「学习器」「测试器」「快速播放器」「闪记」「复习」或「错题专练」。Klik kad di bawah untuk masuk "Pembelajaran", "Ujian", "Pemain Pantas", "Kad Kilat", "Ulangkaji" atau "Latihan Salah".
  3. 添加到主屏幕：iOS 点底部分享按钮 →「添加到主屏幕」；安卓 Chrome 点菜单 →「安装应用」。Tambah ke Skrin Utama: iOS - butang Kongsi → "Tambah ke Skrin Utama"; Android Chrome - menu → "Pasang Aplikasi".
  4. 之后主屏幕就会出现 App 图标，点开即全屏使用，就像原生 App 一样。Selepas itu ikon aplikasi muncul di skrin utama, buka untuk skrin penuh macam aplikasi asli.
提示：看板数据全部来自本机 localStorage，无网络上传。换设备不会自动同步；如需迁移可在每个 app 内用 ⤴ / ⤵ 按钮导出/导入 JSON。Petua: Data papan pemuka disimpan dalam localStorage peranti, tiada muat naik rangkaian. Tidak segerak antara peranti; guna butang ⤴/⤵ dalam setiap app untuk eksport/import JSON.
提示：若点击「播放解说 / 测试」听不到声音，请用 Safari 或 Chrome 打开本页面。Petua: Jika tiada bunyi bila klik "Baca/Ijian", sila buka halaman ini dengan Safari atau Chrome.
